# Promotion Checklist

Use this file when announcing SES Manager for Plesk outside GitHub.

## Short Description

Open-source Plesk extension for routing mail through Amazon SES, automating DKIM/SPF/DMARC DNS records, and tracking SES bounce/complaint events.

## Longer Description

SES Manager for Plesk helps administrators connect Amazon SES to Plesk, create SES domain identities, generate and apply DNS records through Plesk DNS or Cloudflare, configure SES SMTP smarthost delivery, send test mail, monitor DNS health, and collect SES bounce/complaint/delivery events through AWS SNS.

The public build has no license server, no runtime package tiers, and no domain limits.
