# Code of Conduct

## Our Pledge

We want this project to be useful and professional for Plesk administrators, hosting providers, and contributors. Be respectful, direct, and constructive.

## Expected Behavior

- Use welcoming and inclusive language.
- Focus feedback on the technical issue.
- Respect maintainers' and contributors' time.
- Avoid sharing private customer data, server data, credentials, or logs.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing private information without explicit permission.
- Posting secrets, exploit details, or unsafe operational instructions in public issues.
- Repeated low-effort or off-topic comments.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate these expectations. Serious or repeated violations may result in blocked participation.
